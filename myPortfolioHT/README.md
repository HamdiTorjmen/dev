# Alex Morgan CV

A responsive, single-page CV website built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

Replace the sample name, contact details, experience, and project copy in `index.html` with your own information. The **Print CV** button opens the browser print dialog and uses the included print styles for a clean PDF export.
